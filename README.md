# LearnHub - LMS Frontend

A beginner-friendly Learning Management System frontend demo built with HTML, CSS and JavaScript.

## Project structure

```text
LMS-Frontend/
├── index.html
├── courses.html
├── course-details.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Features

- Student dashboard
- Dashboard course search
- Explore six sample courses
- Search courses by name
- Filter courses by category
- Course details loaded from the URL query string
- Learning objectives and course curriculum
- Demo enrollment button
- Responsive layout for smaller screens

## Run the project

1. Open the project folder in VS Code.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Select **Explore courses** to view and filter courses.

## Important note

This is a frontend-only demonstration. Course enrollment, student accounts, progress and course data are not stored in a backend or database.
